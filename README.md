# پروژه من

توضیح کوتاه: این وبسایت با استفاده از HTML، CSS و JS ساخته شده و روی هاست ایرانی قرار می‌گیرد.

## نحوه اجرای لوکال
1. پوشه پروژه را در VS Code باز کنید.
2. افزونه Live Server را نصب کنید.
3. روی index.html راست کلیک کرده و Open with Live Server را بزنید.

## نحوه اتصال به گیت‌هاب
- از SSH استفاده کنید.
- دستورات: git init, git add ., git commit -m "first commit", git remote add origin ... , git push
